**Code Summary:**  
  
### Artifact Loading and Filtering  
  
The code iterates through JSON files in the `./build/contracts/` directory (assuming they exist after running `truffle compile`). It skips the `IterableMapping.json` file. Each JSON file is expected to contain a Solidity contract artifact in the format defined by the `SolidityArtifact` struct (name, ABI, bytecode).  
  
### ABI Binding Generation  
  
For each valid artifact, the code reads the JSON, unmarshals it into the `SolidityArtifact` struct, and then uses the `github.com/ethereum/go-ethereum/accounts/abi/bind` package to generate Go bindings. The bindings are created using the contract name, ABI, and bytecode.  
  
### Output File Writing  
  
The generated Go code is written to a file in the `api` directory, named after the contract (e.g., `MyContract.go`). The file permissions are set to 0600.  
  
### Error Handling  
  
The `dieSoon` function handles errors by printing an error message to the console and exiting the program.
