## Solidity Contract Wrapper Generator Summary

**Package Name:** `main` (executable for generating wrappers)

This program automates the generation of Go wrappers around Solidity contracts based on their compiled artifacts (ABI and bytecode). It reads JSON files from a specified directory (`./build/contracts/*.json`), skips processing `"IterableMapping.json"`, and uses the `github.com/ethereum/go-ethereum/accounts/abi/bind` package to generate Go code that can interact with these contracts. The generated wrappers are written as `.go` files in an output directory named "api".

**Configuration:**

*   **Artifact Directory:** `./build/contracts/*.json` (JSON files containing Solidity contract artifacts)
*   **Output Directory:** `"api"` (where generated Go code is written)
*   **Package Name:** `"api"` (name of the generated Go package)
*   **Excluded Artifact:** `"IterableMapping.json"`

**Usage:**

1.  Ensure that `truffle compile` has been run to generate JSON artifacts in `./build/contracts`.
2.  Run this program from the root directory where both it and the `./build/contracts` folder are located. The generated Go wrappers will be placed inside a newly created "api" directory.

**File Structure:**

*   `generate_api.go`: Main executable file containing the logic for artifact loading, processing, and wrapper generation.
*   `./build/contracts/*.json`: Solidity contract artifacts (generated by `truffle compile`).
*   `api/<contract_name>.go`: Generated Go wrappers for each Solidity contract (excluding `"IterableMapping"`)

**Edge Cases:**

*   If no JSON artifacts are found in `./build/contracts`, the program exits with an error. This indicates that `truffle compile` may not have been executed or the output directory is incorrect.
*   The exclusion of `"IterableMapping.json"` suggests a specific reason for skipping this contract, which might be due to incompatibility or known issues.
